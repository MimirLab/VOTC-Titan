# Security reports

Do not post API keys, GitHub credentials, authentication codes or private RP
transcripts in an issue. Review diagnostic logs before sharing them.

Use GitHub's private vulnerability reporting when enabled for the repository.
If it is unavailable, request a private contact route with a brief non-sensitive
overview, rather than posting exploit details or affected private data publicly.

Authentication belongs in the user's operating-system credential store, not
source code, issue attachments, build artifacts or generated release manifests.
