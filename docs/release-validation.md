# Current preview: validation and scope

The release presentation describes shipped systems, not every experiment in the
private research workspace. Counts are taken from the bundled corpus and active
catalogues. Source metadata and the exact release checksum identify the edition.

## Current update

This edition brings the qualified local updates into the public launcher:
reviewed parent-culture roots, original-faith context and inherited tenet
perspectives; expanded Warcraft practice guidance; combined report and cultural
lore access; and cached lore navigation.

Memory and delivery repairs retain campaign provenance on new summaries, preserve
hidden records during editing, drain accepted actions before closing a chat, and
deliver letters independently of optional diary generation. A narrow English
speech-attribution repair accepts an otherwise valid dialogue form without
changing spoken words or private thoughts.

The default Medivh narrator, approved Troll and Wildhammer casting, scene picker,
installer recovery and XDG integration remain included. Voice recordings,
paintings and the 37,026-passage corpus retain their existing asset hashes.

The source, compiled runtime, desktop checks and extracted installers are tested
together for each release. Exact results and checksums ship in
`release-validation.json` beside the download. Provider regressions use synthetic
responses; narrator checks reuse retained audition PCM. No fresh natural campaign
playtest or new model synthesis is claimed for these repairs.

The public source candidate passes **3,767 tests in 168 suites**, with the same
ten explicit private-evidence skips, plus **38 packaging and installer tests**.
The release checks also compare compiled modules against the qualified local
launcher. The separate graded lore-access research prototype is not part of this
release.

## Game and bridge

GoA2 intentionally pins CK3 to an earlier branch. Use the CK3 version required
by GoA2. Titan communicates with the in-game VOTC Community Edition addon through
CE's command channels and debug log, and reads GoA2 game facts through that bridge.
The working tested stack is **CK3 1.19.0.6, GoA2 0.6.5 and VOTC CE 2.5.0**.
A newer CK3 label in CE's launcher descriptor is metadata, not evidence of a
runtime incompatibility. Report an actual command, probe, log or script failure
when identifying a bridge compatibility defect.

## Earlier foundations

The preceding launcher-only release passed **3,507 tests in 150 suites**, four
native desktop reports and wide/narrow Electron scene-art checks. An isolated
paused CK3 campaign using subscribed CE/GoA returned current world/character state
and a numeric clock through CE, observed language study and exercised a fixture
trace. A combined lore/scene probe completed in 0.51 seconds including CE polling.
That is a finite bridge check, not a normal full-RP latency guarantee.

The cleaned source candidate passed **3,506 tests in 151 suites**, with ten
explicit private-archive/integration skips, before this presentation work. A real
fresh locked dependency install, TypeScript compilation, eight maintenance tests
and 20 packaging/import/installer tests also passed during access preparation.
The latest upload-specific results are recorded in the GitHub source-check run
and the downloadable release notes.

## Interpretation

- Corpus coverage means 37,026 structured passages in this assembled edition.
  It does not certify every Warcraft fact or guarantee hallucination-free prose.
- The 141 GoA2 branch accounts exceed the nine automatic retained-trace bindings.
  Missing historical evidence is left unknown, not reconstructed from dates.
- Voice coverage means 419 prepared banks for 407 named identities. It does not
  prove every rendered line's audible identity, words or performance quality.
- Private listening evidence and approvals remain private; unresolved experimental
  sounds are not described as live just because they rendered successfully.
- Full tests use the verified runtime asset bundle. The hosted source workflow
  checks compilation, maintenance routing and packaging guards without model or
  game calls; it is not the entire native acceptance suite.
- The current native target is Linux x64/X11, exercised on EndeavourOS/Arch.
  Different distributions, Windows/macOS, native Wayland and newer game/addon
  combinations require additional qualification.
