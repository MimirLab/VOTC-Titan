# Contributing to VOTC Titan Edition

Titan is maintained under MimirLab as a GoA2-focused roleplay launcher. Report
Titan issues in this repository, keeping game and provider versions in reports.
Original VOTC, Community Edition and other upstream contributors retain credit.

Use a branch and pull request for maintenance. Keep runtime integration in the
launcher; do not introduce required Workshop edits, a Titan game fork or a Steam
wrapper. Preserve campaign identity, saved voices, histories and player settings.

See README and docs/github-release-preparation.md for source setup and verified
runtime-asset import. Run npm ci, npm run build and npm test -- --runInBand.
Private listening-study comparisons are explicitly optional when their evidence
is absent. Do not turn a production regression into an archival skip.

Use recorded fixtures for routine tests. Run real model/game checks deliberately
and within resource limits. Explain the relevant validation and material limits
in the pull request. Bundled recordings, fonts, artwork and lore retain their own
terms; a new contribution must preserve their provenance and notices.
